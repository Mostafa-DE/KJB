Source code

- KJB's own code in the add-on (dl-addon and addon-shared) is in KJB's repository, https://github.com/Mostafa-DE/KJB,
  at the tag of each release.
- youtubedl-android 0.18.1 is used as published on Maven Central (io.github.junkfood02.youtubedl-android: library,
  ffmpeg and common). Its Java source is published beside it there, as library-0.18.1-sources.jar,
  ffmpeg-0.18.1-sources.jar and common-0.18.1-sources.jar
  (https://repo1.maven.org/maven2/io/github/junkfood02/youtubedl-android/), and its repository is
  https://github.com/JunkFood02/youtubedl-android.
- The programs and libraries youtubedl-android carries (Python, FFmpeg and every library listed under them below) are
  the Termux project's builds for Android, packed by youtubedl-android without change (Python's in libpython.zip.so,
  FFmpeg's in libffmpeg.zip.so). Termux's build script and patches for each are in
  https://github.com/termux/termux-packages (packages/<name>/build.sh and the patches beside it). The source of each
  project, at the version named below, is at the address named below.
- yt-dlp, yt-dlp-ejs, mutagen and PyCryptodome ship as their source (Python and JavaScript).

Jackson is a high-performance, Free/Open Source JSON processing library.

commercially by FasterXML.com.
